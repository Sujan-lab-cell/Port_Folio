## 9. FlyRank — Search Performance Decline Prediction & SEO Prioritization
- **Category**: Machine Learning, Industry Project, Ranking
- **Summary**: Large-scale ML decision-support system for predicting search performance decline and prioritizing SEO content reviews across ~78.8 million search performance records.
- **Technologies**: Python, Pandas, DuckDB, NumPy, Scikit-learn, Random Forest, XGBoost, LightGBM, CatBoost, Matplotlib
- **Key Metrics**:
  - Analyzed ~78.8 Million daily search records.
  - Achieved Precision@50 of 0.444 vs 0.392 baseline (+5.2 percentage points).
  - Used client-grouped 5-fold cross-validation to eliminate cross-client data leakage.
- **Research Paper**: https://sujan-lab-cell.github.io/flyrank-ml-internship/
- **GitHub Repositories**:
  - https://github.com/Sujan-lab-cell/flyrank-ml-internship
